-- DESCRIPTION --

A modern, responsive web application for managing your personal culinary collection. Built with Blazor and .NET, this project demonstrates a clean architecture for CRUD operations, search functionality, and a seamless user experience.

-- FEATURES --

-Create & Edit Recipes: Add new culinary masterpieces with titles, ingredients, and step-by-step instructions.

-Search & Filter: Quickly find that one pasta dish using the real-time search bar.

-Responsive Design: View your recipes on a desktop, tablet, or smartphone—perfect for use in the kitchen.

-Blazor Component Architecture: Reusable UI components for a fast, single-page application (SPA) feel.

-- TECH STACK --

-Frontend: Blazor WebAssembly (or Server)

-Backend: .NET 8.0 SDK

-Styling: CSS3 / Bootstrap
